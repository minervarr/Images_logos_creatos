# Images_logos_creatos

Glyph and logo image generator: `glyphpng.cpp` / `glyphpng.py` render PNG
logos from the definitions in `logos.json` and `bundles.json`
(`Makefile` to build). `pictures/` holds the source art, `assets/fonts/`
the typefaces, `texts.txt` the label corpus.

Consumed by the sibling minervarr projects that need baked icon/logo
assets (Matrix Player's `tools/icon_font` pipeline among them).
